## 1. 我们在做什么（别再跑偏）

帮**不懂设计的小卖家**：上传一张商品图 → 几步内拿到一张能直接用的商品图。
就这一件事。不是 Photoshop，不是 prompt 工程平台。每一屏都要**替用户少做决定**。

**这一阶段的目标 = 修产品体验，不是追 bug。** 判断标准只有一个：一个真人能不能自己走完、不卡壳、对结果满意。

## 3. 代码现在真实是什么样（大白话，已核对）

- **流程**：入口页 → 选场景（5 类，目前是旧词「模板/类目」）→ 上传商品图 → 微调（默认 1:1 / 1 张）→ 生成 → 结果/失败。能返回，登录不被挡。
- **失败时（最劝退）**：直接把 `Sub2API / ConnectError` 这种内部报错甩给用户；**没有重试按钮**；右侧任务栏还会**暴露完整内部 prompt**；而且 `addTask()` 会自动弹出任务栏**打断创作**。
- **登录**：之前慢到 8 秒像卡死。已把后端鉴权超时从 300s 降到 8s（改动在 `backend/app/auth_client.py` + `main.py`，**未提交**，等上游恢复后量一次确认）。
- **上传示例图**：用的是外网 Unsplash 图，会裂、也不是真实出图。
- **上游 sub2api**（`sub.chris233.qzz.io`）目前宕机，登录/生成都依赖它——这是已知外部风险，不是本项目代码 bug。

### 第 1 件事的验收标准（做对了算什么 — 上线门槛）

涉及文件：新建 `src/lib/presentTaskError.ts`（错误→中文文案映射）；改 `tasks.tsx`(停止 addTask 自动弹抽屉 + 加 retryTask)、`TaskDrawer.tsx`(用映射 + 藏 task.prompt + 加 lime 重试)、`Create.tsx`(TaskResultRow 用映射 + 卡内重试 + addTask 不自动开)、`Workspace.tsx`(详情用映射 + 藏 prompt)、`notifications.ts`(失败 toast 走映射不走原始 message)。

- **Given** 生成失败返回 `Sub2API…ConnectError`（或 503/502/超时），**When** 用户在 Create / TaskDrawer / Workspace 看到，**Then** 显示中文人话（标题「这次没生成成功」+「出图服务繁忙，请稍后重试」），且渲染 DOM 里**永不出现** `Sub2API`/`ConnectError`/任何 HTTP 状态文本。
- **Given** 任一失败/进行中任务，**When** 抽屉或详情渲染，**Then** 完整内部 prompt（`Amazon-compliant…`/`未填写`）**不显示**；只显示用户自己填的补充需求，或什么都不显示。
- **Given** 失败任务，**When** 用户在 /create 或抽屉看到它，**Then** 有一个 lime「重试」按钮，一键用同一张图+同设置重提，无需离开或重新上传。
- **Given** 用户在 /create 提交生成，**When** addTask 触发，**Then** 全局任务抽屉**不自动弹**；结果就地显示，抽屉只在用户主动点击时才开。
- **Given** `task.error` 为空的失败任务，**When** 渲染，**Then** 4 个展示点都显示兜底「出图服务暂不可用，请稍后重试」，不出现空红框。

**上线门槛**：上游现在就挂着可随手复现失败——4 个展示点都中文人话 + 可用卡内重试；抽屉/详情看不到内部 prompt；失败界面 DOM 扫描零 `Sub2API`/`ConnectError`/`未填写`；/create 提交后不再自动弹抽屉。

### 要埋的指标（边做边埋，证明修对了）
- `error_humanization_rate`（失败渲染走映射的占比，目标 100%）、`prompt_leak_audit`（失败界面里内部串出现次数，目标 0）
- `task_retry_clicked`（失败后卡内重试点击率）、`drawer_auto_open_rate`（/create 提交后自动弹抽屉率，目标 0%）
- 全旅程：`cta_start_create_clicked`、`scene_selected{customer,scene}`、`upload_completed{is_touch}`、`tune_defaults_kept`、`generate_submitted{count,cost,balance}`、`recharge_gate_funnel`、`ecommerce_download_clicked`
