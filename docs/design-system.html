AetherGenix

Design System v1

暖炭黑 · 电石灰签名 · 深色优先 · Lovart 风格 · Tailwind CSS v4

字体：Inter · Bricolage Grotesque · JetBrains Mono 主色：#E3FF74 底色：#111110
01 概览 & 优化机会
当前设计优势：暖炭黑底色有质感、电石灰签名色辨识度强、按钮三级体系清晰、毛玻璃 Nav 精致。这套风格定位是「创作者工作台」，应当保留。
对比 Pebblely 后发现的提升机会
维度当前状态优化方向优先级
电商模板选择✗ 文字按钮，无视觉预览→ 视觉缩略图网格，带场景预览P0
输出格式/尺寸✗ 无尺寸/用途选项→ 格式卡片选择（主图/信息流/竖版）P0
商品图持久化✗ 每次重传，无产品库→ 产品库卡片组件P0
批量数量选择✗ 无→ 1/2/4 count chips + 按钮显示「生成 (N)」P1
结果微调✗ 无就地编辑→ 文字描述微调，不重传P1
CTA 在电商页的力度ghost 风格偏弱→ 电商场景专属 CTA 按钮（更大，矩形圆角）P1
Credit 透明度✗ 不显示消耗预估→ 按钮显示「生成 (4)」—— N 实时更新P2
批量下载✗ 无→ 复选框 + 批量下载按钮P2
