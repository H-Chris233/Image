# ADR 0001 · 路由拆分：/create + /workspace/:taskId + /explore

**状态**：已决定  
**日期**：2026-05-18

## 背景

原有代码将「生成输入」和「灵感图库浏览」混合在同一个 Home (`/`) 页面。用户的生成结果也混入公开灵感 feed，导致个人工作流与浏览场景互相干扰。

同时，原有的「电商生成」是独立路由 `/ecommerce`，与通用生成形成割裂的两个入口。

## 决定

将产品拆分为三条独立路由：

- **`/create`**：已登录用户的创作入口，包含通用和电商两种生成模式（扇形卡片切换）
- **`/workspace/:taskId`**：生成完成后的专属操作台，有独立 URL
- **`/explore`**：未登录用户的落地页，纯浏览灵感图库

**`/`** 作为分流路由：已登录 → `/create`，未登录 → `/explore`。

## 被放弃的方案

- **保持 Home 混合布局**：生成和浏览在同一页面，缺点是焦点分散，历史记录与灵感内容视觉上难以区分
- **生成结果用 Drawer 展示**：不产生独立 URL，无法书签，历史页无法直达具体结果
- **`/ecommerce` 保持独立路由**：与通用生成形成功能重叠但入口割裂的体验

## 影响

- `/history` 中每条记录点击后跳转 `/workspace/:taskId`，历史变为操作台入口列表
- 桌面侧边栏主功能组：创作 / 历史 / 收藏（探索不进导航）
- 移动端底部 Tab Bar：创作 / 历史 / 收藏
- 需要新建 `/explore`、`/create`、`/workspace/:taskId` 三个页面组件
- 当前 `Home.tsx` 需要重构拆分
- 登录和注册共用同一套 Modal，内部切换两种表单
- 未登录用户在 `/explore` 点击「复用提示词」→ 弹登录 Modal → 登录成功后自动跳 `/create` 并预填 prompt
