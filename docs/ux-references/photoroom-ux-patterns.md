# Photoroom — UX 模式提取

> 分析时间：2026-05
> 产品定位：AI 商品图制作，SaaS + Mobile App，面向商家/设计师

---

## 1. 首屏价值传递

**核心设计：产品定位 + 功能预览 + 示例作品**

- Headline: "Make product images that sell"（6个字精准锁定目标用户）
- 首屏展示：6 张真实商品的 Before/After 效果轮播（手机壳、香水瓶、运动鞋…）
- 拖拽上传区占屏 50%，同时展示"Try one of our samples"快捷链接
- 不同于 Remove.bg 的"抠图单功能"，Photoroom 在首屏就展示 3 个场景选项卡：Background / Scene / Edit

**关键数字：用户看到首屏后能立即理解"它能帮我把商品放进真实场景"**

---

## 2. 上传→结果最短路径

```
进入页面
  → 拖拽商品图（或点击 "Try Sample"）
  → [2秒：自动背景移除]
  → 看到白底商品图 + 右侧场景模板面板
  → 点击一个场景模板
  → [3秒生成]
  → 下载
```

**路径步数：3 步**（上传 → 选场景 → 下载），其中步骤 2 是可选的，有默认场景

---

## 3. 空状态设计

| 状态 | 内容设计 |
|------|---------|
| 首次进入 | 大拖拽区域，下方"Try our samples"展示 6 张商品缩略图可一键尝试 |
| 背景已移除，等待选场景 | 右侧模板面板自动展开，商品已在画布中居中，引导视线向右 |
| 无模板选择 | 默认白色背景，浮现"Select a background"提示气泡 |
| 生成中 | 画布区淡入进度动画，模板缩略图上出现选中状态，无独立 loading 页 |
| 生成成功 | 结果直接替换画布，右侧面板出现"Generate more"选项 |
| 批量上传为空 | "Drag 1-100 product images here" + 文件夹拖拽图标 |

---

## 4. 结果反馈与迭代机制

- **多模板快速预览**：点击模板缩略图即刻切换效果，无需重新生成
- **画布内编辑**：生成后可直接拖拽商品位置、调整大小，不需要重新配置
- **Generate More**：一键重新生成同场景的变体
- **Batch Apply**：同一场景应用到上传的所有商品，批量输出
- **Smart Padding**：自动给商品添加合适的留白，商品不会贴边

## 5. 可复用 UX 模式

### P05 — Sample Products as Onboarding（样本商品作为 Onboarding）
> 提供 6-8 个预置样本商品（不同品类），用户点击即可体验完整流程，无需先上传自己的图。

**Apply to AetherGenix**：在首次进入/未登录状态展示"试用示例商品"功能。点击某个示例商品（如：咖啡杯），直接跳入配置-生成流程，让用户先见到价值再登录。

### P06 — Product-in-Scene Template Thumbnails（场景内置商品的模板缩略图）
> 模板缩略图中展示**真实商品合成在场景中**的效果，而非单纯的场景背景色或渐变。

**Apply to AetherGenix**：将 TemplatePicker 的渐变色缩略图替换为：用通用商品图（如白色方盒子/手机）预合成在该场景中的效果图。用户选模板时即可预判"我的商品放进去大概是什么效果"。

### P07 — Type-Aware Scene Suggestions（商品类型感知的场景推荐）
> 上传图片后 AI 自动识别商品类型，优先展示该类型最常用的场景模板。

**Apply to AetherGenix**：现有 `handleAnalyzeProduct` 函数已能分析商品类型，利用分析结果自动高亮最相关的风格模板（如识别到食品 → 高亮室内场景和户外自然；识别到数码 → 高亮商业海报）。

### P08 — Canvas-First, Form-Later（画布优先，表单延后）
> 核心交互在可视化画布/预览区，参数配置是辅助功能，不是主要界面。

**Apply to AetherGenix**：将"生成结果预览区"提升到首屏可见位置，表单折叠为侧边栏或底部面板，让用户的注意力聚焦在"看到效果"上，而非"填完表单"。

### P09 — Instant Background Switch（即时背景切换）
> 已生成结果后，可一键切换场景而不重新生成所有内容（商品分层独立）。

**Apply to AetherGenix**：高级功能，需要后端支持图层分离。记录为 Advanced UX 阶段目标。

## 6. 关键差异（vs 当前 AetherGenix）

| 维度 | Photoroom | AetherGenix 当前 |
|------|-----------|-----------------|
| 模板缩略图 | 真实商品+场景合成图 | 纯色渐变 |
| 表单填写 | **无表单**，AI 自动 | 7+ 个文本输入框 |
| 空状态 | 展示 6 个可点击样本商品 | "上传商品主图"图标+文字 |
| 结果迭代 | 点击缩略图即切换 | 需重新配置表单后重新生成 |
| Onboarding | 无需注册可试用 | 需登录才能生成 |

---

## 关键启示

> **Photoroom 把"让商家快速看到可用的商品图"作为唯一 KPI**。  
> 一切设计（AI 自动裁剪、场景预览、批量导出）都服务于降低商家从"原始商品图"到"可发布商品图"的时间成本。  
> **表单是失败的交互——AI 自动识别是成功的交互。**
