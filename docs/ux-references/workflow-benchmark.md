# 工作流范式对标研究
## AetherGenix 电商生图 vs 一流商业工具

> **研究日期：** 2026-05-25  
> **研究目的：** 诊断 AetherGenix `/ecommerce` 工作流与商业级生图工具的本质差距，为范式升级提供依据。  
> **研究范围：** 9 款工具（6 款国际 + 3 款国内），涵盖 AI 生图/电商图/设计三个细分赛道。

---

## 一、工作流范式分类法

经过对 9 款工具的一手调研，识别出 AI 生图工具的 **5 种核心工作流范式**：

| 范式 | 代表产品 | 用户第一步 | 到首张结果所需操作 | 核心心智模型 |
|------|---------|-----------|-----------------|-------------|
| **P1 — Prompt-First** | Ideogram、Midjourney | 输入文字描述 | 1步（写词→回车） | "用语言召唤图像" |
| **P2 — Upload-First 即时结果** | Photoroom、Remove.bg | 拖拽上传图片 | 1步（上传→自动处理） | "AI 帮你抠/换背景" |
| **P3 — Template-First** | Pebblely、万相营造、豆绘AI | 选择场景/模板 | 2步（选模板→上传商品） | "套模板，商品放进去" |
| **P4 — Canvas-First 实时预览** | Krea.ai、万相(画布) | 打开画布即开始 | 1步（落笔即见） | "所见即所得的创作台" |
| **P5 — Agent 对话式** | Lovart、万相(Agent模式) | 用一句话描述需求 | 1步（对话→AI全权完成） | "我告诉 AI 要什么，它自己决定怎么做" |

## 二、各工具详细分析

### 🌍 国际工具

---

#### Ideogram.ai — Prompt-First 典范

**核心工作流：**
```
打开页面 → 看到居中大文本框 "What will you create?"
→ 输入描述 → 回车 → 内联展示4张结果图（右侧无需切屏）
```

**关键设计决策：**
- 中心文本框是唯一 CTA，视觉权重占页面 80%
- 类别 chip（General / Poster / Photography / T-shirt / Logo）提供快速语义引导，减少"空白焦虑"
- 结果直接显示在当前视口，**零跳转**
- 历史图、社区图与创作入口同屏并排，形成「结果即灵感」的飞轮
- 高级选项（风格/尺寸/比例）折叠在输入框下方，按需展开

**用户认知负担：** ⭐（极低）  
**到首张结果步骤数：** **1 步**

---

#### Midjourney — Prompt-First + 强社区探索

**核心工作流：**
```
打开 midjourney.com → 进入 Explore 页（瀑布流顶级作品）
→ 点左侧图标切换到 Create → 输入 /imagine [prompt] → 生成
```

**关键设计决策：**
- Explore 页作为冷启动缓冲区，消除"我不知道能生成什么"的焦虑
- 极简图标侧边栏（无文字标签），操作语言类 Figma
- Discord 原生交互迁移到 Web 后保持「命令行风格」，反而成为专业感标志
- 结果 2×2 网格内联显示，U1/U2/U4/V1 按钮立即可操作

**用户认知负担：** ⭐⭐（有学习曲线但有高级感）  
**到首张结果步骤数：** **2 步**（进入 Create → 输入 prompt）

---

#### Krea.ai — Canvas-First 实时生成

**核心工作流：**
```
Launch App → 画布界面 → 画/上传图 → 实时流式预览同步更新
```

**关键设计决策：**
- 主打「实时生成」（Real-time Generation）：每次笔触都触发后台推理，结果在右侧实时刷新
- 上传参考图后 AI 即时 enhance/transform，没有「提交等待」的概念
- 功能矩阵极广（Image / Video / Upscale / AI Studio / Pricing），但入口统一在画布
- 品牌定调：*"the world's most powerful creative AI suite"*，面向专业创意人

**用户认知负担：** ⭐⭐⭐（功能强大，需要一点探索）  
**到首张结果步骤数：** **1 步**（画布上落笔/上传即见结果）

---

#### Pebblely — Template-First 电商专精

**核心工作流：**
```
Get started → 上传商品图（背景自动抠除）
→ 从模板库选择场景背景 → 一键生成产品场景图
```

**关键设计决策：**
- 「抠图」是隐形的第一步——上传即自动完成，**用户感知不到技术成本**
- 场景模板库是真正的核心资产：按用途分类（季节/节日/室内/户外），视觉缩略图一目了然
- 选中模板后右侧**即时预览**（商品合成到场景中的效果），不用提交就能看大概
- 批量生成：同一张商品图 × N 个场景 → 一次输出
- 面向 Shopify/亚马逊卖家，UI 语言非常产品化：*"Create AI product photos that help you sell more"*

**用户认知负担：** ⭐（极低，对电商卖家最友好）  
**到首张结果步骤数：** **2 步**（上传商品图 → 选模板）

---

#### Leonardo.ai — Creator-First 综合平台

**核心工作流：**
```
Create → 文字生图 / Image-to-Image / Canvas / 3D Texture
→ 模型选择（10+ 风格模型）→ 生成
```

**关键设计决策：**
- 品牌定位「Creator-First」，面向艺术家和专业创作者
- 多模态入口并列（生图/图生图/画布/3D），但主页是单一文本输入
- 强调「模型选择」——不同 checkpoint 生成完全不同风格
- 紫黑配色视觉识别度高

**用户认知负担：** ⭐⭐⭐（选项多，专业用户友好）  
**到首张结果步骤数：** **2 步**（选模型 → 输入 prompt）

---

#### fal.ai — Developer-First API 平台

> 不在本次 UX 对标范围内。面向开发者而非终端用户，UI 是 API 文档 + Playground 形态。  
> **对 AetherGenix 的参考价值：** fal 的 Playground 展示了「输入参数面板 + 实时图片预览」两栏并排的开发者友好布局，可借鉴用于高级配置面板设计。

### 🇨🇳 国内工具

---

#### 豆绘AI (douhuiai.com) — 多模态全场景电商平台

**核心工作流（通用模式）：**
```
首页中央文本框 → 输入描述 → 选模型（GPT图像-2/其他）
→ 选比例 → 生成 → 右侧内联展示
```

**核心工作流（电商专项）：**
```
左侧「电商商品图」导航 → 选具体工具
（一键场景图 / 一键白底图 / 卖点图 / 试穿 / 精修）
→ 上传商品图 → 一键生成
```

**关键设计决策：**
- 中央输入框 + 快捷 chip 组合（类 ChatGPT），降低通用生图的门槛
- 侧边栏把复杂功能拆解成**独立工具模块**，用户按需进入，不会在一屏看到所有选项
- **电商功能是独立产品线**，不与通用生图混在一起——卖家只看卖家需要的 UI
- 快捷入口 chip 直接通往热门垂类（场景图/白底图/试穿），一次点击到专用工作流
- 实时进度条 + 分阶段文字提示，等待期间有反馈

**用户认知负担：** ⭐⭐（通用简单，专项需要选入口）  
**到首张结果步骤数：** **1~2 步**（通用 1 步；电商专项 2 步：选工具→上传）

---

#### 万相营造 (Alibaba Mama) — 商家专属电商图生产线

**核心工作流：**
```
登录淘宝/天猫商家账号 → 选工具模块
（万相融绘 / 自动化创意 / AI商品图 / AI服饰）
→ 选「融合创意」场景模板 → 上传商品主图 → 配置风格 → 批量生成
```

**关键设计决策：**
- **直接打通淘宝商品数据**：商品主图可从店铺库存一键拉取，无需单独上传
- 「模板选择」是主交互：先选风格模板（展示最终效果的视觉缩略图），后填配置
- 支持「商品数字孪生训练」：上传多角度商品图，AI 训练出专属商品模型后可多次复用
- 批量生成是核心价值：一次任务可输出数十张不同场景的商品图
- 深度集成阿里体系（达摩院、妙鸭等技术栈），商家端运营工具而非消费者产品

**用户认知负担：** ⭐⭐（需要阿里账号，但对淘宝卖家来说是熟悉的"卖家中心"语言）  
**到首张结果步骤数：** **2~3 步**（选模板 → 上传/拉取商品图 → 生成）

---

#### Lovart (lovart.ai) — Agent 对话式全能设计智能体

**核心工作流：**
```
打开对话框 → 输入一句话（"为跑鞋产品页面设计视觉素材，
包括主图、产品特写和运动员上脚照"）
→ Agent 自动：分析意图 → 搜索参考 → 调研品牌 → 生成完整资产集
→ 画布左侧显示设计资产（主图+特写+场景图），右侧是对话记录
```

**关键设计决策：**
- **零配置**：用户只需说出目标，不需要选模型/尺寸/风格
- Agent 主动展示推理过程（"正在搜索高质量参考图…"），等待期有认知锚点
- 输出不是单张图而是**一套资产**（主图 + 特写 + 场景图 + 视频素材）
- 画布与对话面板左右并排，资产可直接拖拽编辑
- 定位「新生代创作者」，解决「从零到品牌视觉体系」的全链路问题

**用户认知负担：** ⭐（极低——说话就行，不需要任何专业知识）  
**到首张结果步骤数：** **1 步**（发送一条消息）

## 四、AetherGenix 现状诊断

### 4.1 范式定位

AetherGenix 当前属于 **"表单驱动 + 异步任务"** 范式——这是所有范式中用户体验最差的一种，在商业产品中几乎已绝迹。

```
用户当前路径（实测）：
① 上传商品图（需要明白这是必填项）
② 填写商品名称（★ 必填，但不明显）
③ 选择风格模板（6 个视觉缩略图，还算OK）
④ 选择格式/比例（4 张格式卡片）
⑤ 选择数量 chip
⑥（可选）展开高级选项 → 填描述/材质/卖点/场景
⑦ 点击「✦ 生成场景图 (N)」按钮
⑧ 等待 → 看到 3 阶段进度条
⑨ 【任务进入后台任务抽屉，需要打开抽屉查看】
⑩ 结果出现在下方「历史记录」区（需要手动滚动或等自动滚动）
```

**问题总结：**

| 问题类型 | 具体表现 | 对标差距 |
|---------|---------|---------|
| 🔴 **步骤过多** | 7+ 步到首张结果 | 对标工具 1~2 步 |
| 🔴 **结果不在视口内** | 结果在任务抽屉或历史区，需要切换视图 | 所有对标工具结果均内联显示 |
| 🔴 **没有即时反馈** | 提交后跳入"等待中"状态，进度条是补丁 | Krea 实时流式；Pebblely 即时预览 |
| 🟡 **空白状态弱** | SampleGallery 只是静态展示，无法互动 | Ideogram/Midjourney 展示真实社区作品 |
| 🟡 **上传图片后无响应** | 上传商品图后 UI 无任何视觉确认/分析反馈 | Pebblely 上传即自动抠图，有即时视觉响应 |
| 🟡 **模板无预览效果** | 模板选择器是渐变色块，非真实生成效果示例 | Pebblely 模板缩略图是真实商品合成效果 |
| 🟡 **批量生成体验弱** | 数量 chip 改数字但结果管理无专门 UI | 万相营造 / 豆绘AI 有批量任务管理 |
| 🟢 **相对亮点** | GenerationProgress 三段式进度条有专业感 | 优于大多数工具的 spinner |

### 4.2 根本矛盾

> 用户的心理模型是「看效果」，AetherGenix 提供的是「填表格」。

一流工具的设计原则是：**结果先行，配置后置**。
- Pebblely：先看场景模板的真实效果，选中再上传商品
- Ideogram：先看社区生成的结果，产生"我也要试"的冲动
- Krea.ai：实时看到效果，再精调参数

AetherGenix 目前是反向的：先填完所有参数，才能看到任何结果。

## 五、推荐范式升级路径

### 方向：从「P0 表单驱动」升级为「P3 Template-First + 内联结果」

**目标体验（Pebblely 变体，适配中文电商）：**

```
① 进入页面 → 看到一排场景模板缩略图（用真实生成图，非色块）
② 选中模板 → 右侧/下方出现「效果预览框」（商品位置用占位符）
③ 上传商品图 → 自动抠图 → 占位符替换为真实商品
④ 点击「生成 (N 张)」→ 结果在同页面内联替换占位符
```

**核心原则（4 条）：**

1. **结果展示区先于配置区**：页面布局上，右侧/下方先放结果展示区（初始为示例图），左侧放配置。
2. **上传即响应**：商品图上传后立即执行背景分析/抠图，给出视觉反馈，不需要用户再点任何按钮。
3. **零跳转结果**：生成结果直接显示在当前页，不进入任务抽屉，不需要滚动。
4. **渐进式配置**：默认只显示「模板选择 + 上传」，格式/数量/高级选项收起，让用户「2 步就能看到第一张结果」。

### 分阶段实施建议

| 阶段 | 改动 | 预期提升 | 工作量 |
|------|------|---------|-------|
| **Phase A（快）** | 在当前页添加「结果预览区」，生成完成后自动填充（不再只进任务抽屉） | 解决「结果不可见」问题 | S |
| **Phase B（中）** | 模板缩略图从渐变色块改为真实生成示例图，点击模板触发「用样例结果预填」 | 解决「选模板无意义感」问题 | M |
| **Phase C（大）** | 商品图上传后立即触发背景分析（show skeleton + 抠图预览），不等用户提交 | 解决「上传无响应」问题 | L |
| **Phase D（核心重构）** | 双栏布局：左侧配置（模板+格式+高级），右侧常驻结果展示区；结果内联替换而非历史滚动 | 从 7 步缩短到 2~3 步 | XL |
