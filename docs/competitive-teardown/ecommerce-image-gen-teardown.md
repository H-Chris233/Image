### 4.3 SWOT 分析

#### AetherGenix SWOT

| 象限 | 内容 |
|------|------|
| **Strengths** | ① AI 产品分析（独有差异化，竞品无）<br>② 设计体系高端感（ag-lime + Bricolage Grotesque，区别于同质化 SaaS）<br>③ Template-First 重构已完成（3 步路径对齐竞品水平）<br>④ ResultPanel 内联结果（Step 1 已解决核心痛点）<br>⑤ 技术栈现代（React + Vite，开发速度快） |
| **Weaknesses** | ① 功能宽度落后（无试穿、精修、卖点图）<br>② 无批量生成（电商卖家高频需求）<br>③ 模板缩略图仍是渐变色块（exampleImageUrl 接口已留，待内容填充）<br>④ 无电商平台集成（Shopify/淘宝）<br>⑤ 社区/内容飞轮为零（无示例画廊） |
| **Opportunities** | ① 利用 AI 产品分析做「智能推荐风格」——上传商品自动推荐最匹配的模板（竞品均无）<br>② 接入 Shopify API 打通海外卖家工作流<br>③ 建立「风格模板生态」——允许用户提交 exampleImageUrl（UGC 飞轮）<br>④ 批量生成：1 商品 × 全部模板 × 1 键输出（差距最大但机会最高的功能）<br>⑤ 中文电商市场：豆绘AI/万相营造 偏重阿里生态，独立站卖家缺乏工具 |
| **Threats** | ① Pebblely 在全球独立站卖家中已建立品牌认知<br>② 豆绘AI 功能矩阵已覆盖 80% 电商场景，且国内地推优势<br>③ 万相营造 的淘宝数据直通是护城河——难以复制<br>④ Lovart 的 Agent 范式若成熟，将使所有「配置型」工具失效<br>⑤ GPT-4o / Gemini 图像能力提升，平台型产品可能被集成压缩 |

### Slide 5 — UX 亮点对比
**他们做得更好（3 条）：**
1. Pebblely：选中模板即时合成预览——用户还没提交就能「看到效果」
